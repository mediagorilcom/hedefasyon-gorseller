# hedefasyon-gorseller

@hedefasyon Instagram sayfasının otomasyon tarafından üretilen gönderi görselleri. Instagram İçerik Yayınlama API'si görseli herkese açık bir URL'den çektiği için burada tutulur; her görsel `YYYY/MM/DD-slot.png` yolunda, yayından sonra da arşiv olarak kalır.

Üretim: https://github.com/mediagorilcom/hedefasyon-otomasyon (özel). Film/dizi kareleri ilgili stüdyolara aittir; TMDB üzerinden alınmıştır.
